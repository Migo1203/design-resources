# 商业提案工作流程

目标：先让 Migo 看懂并选择值得制作的创意，再进入素材、提示词与 Photoshop 执行。适用于产品电商 KV、品牌活动、IP 和艺术类项目；任务类型变化时调整判断标准。

**当前状态：已建立工作入口与模板，尚未开展一轮真实提案验证。** 审美参考、方向选择与实际修订只记录已经发生的内容；模板齐全不代表商业创意能力已验证。

## 一轮提案怎么做

1. **固定 Brief。** 读取真实产品、品牌资料与既有决定，仅补影响当前选择的缺口。将已确认事实、推导或创意假设、待确认问题分开；同轮方向使用同一份 Brief 和事实边界。
2. **实际看图。** 从参考包挑选与本轮目标相关的作品，读取可辨认的图片，记录查看日期与具体图号。拆解摄影、字体、构图、材质及它们的商业作用；网页标题、文字介绍或缩略到不可辨认的图片不足以支持细节判断。
3. **发展三个方向。** 以不同的创意机制和画面结构回答同一商业问题，说明为什么适合产品与受众。换底色、滤镜或装饰不能单独构成三个方向。
4. **交付可看的提案。** 使用真实参考缩略图、色板、可用字体样张与构图线框组成 HTML 或 PDF。标明参考、示意与待定内容；无需 AI 直接生成图片，也不把线框冒充成图。
5. **记录选择并修订。** Migo 可以选中、否决、组合或要求修改方向。记录针对哪一张图、哪一处设计以及原因；AI据此改提案，保留版本关系。没有回复时状态仍为待评审。
6. **进入制作并回看。** 方向清楚后才交付当前阶段确需的提示词和 PS 执行步骤；由 Migo 制作。检查关键画面是否落实了概念，之后再展开系列。将反复有效的方法列为 Skill 候选；本次只建验证记录，不修改技能。

## 提案评审要能回答

- 三个方向分别让受众理解或记住什么，为什么与产品相关？
- 每个方向的核心视觉关系是什么，遮住标题后还能看见哪些支撑？数值与性能仍由资料和文字说明证明。
- 参考中的哪些机制被借鉴，哪些品牌资产、角色或独特表达不沿用？
- 摄影、字体、构图、色彩和材质如何服务商业目标，而非只说“高级”“好看”？
- 现有产品图、字体和制作能力是否支持执行？缺少哪些素材或确认？
- 哪些属于用户当次审美选择，哪些是可观察的制作问题，哪些仍未验证？

## 与已有项目衔接

`design-resources`保存参考、拆解、提案与评审方法；`AIGC`保存真实作品项目、产品资料、制作迭代与采用结果；`AI-Skills`保存经过验证的工作方法。已有项目先引用它的当前 Brief 和采用记录，不在这里建立相互冲突的第二套进度。

启动一个实际项目时，在本目录建立独立项目文件夹，复制所需模板并填写，不覆盖模板。复制后按项目目录深度校对相对链接，引用原始参考和项目资料，避免生成第二套不一致的数据。先完成一轮有真实参考、可看提案和用户反馈的验证，再决定是否扩大流程。
