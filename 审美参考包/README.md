# 审美参考包

这里保存 Migo 的真实审美选择及逐图分析，服务于后续电商、品牌、IP、艺术与商业 KV 提案。网站收藏放在[资源目录](../readme.md)；具体作品、图片和选择理由放在这里。

**当前状态：结构已建立，尚无本轮用户选定的参考作品或已完成的看图拆解。** 目录名、推荐网站和历史成图采用记录都不能自动算作本包中的审美认可。

## 从这里开始

1. 提供作品链接或仓库内图片路径，说明喜欢、不喜欢或尚未决定；首批可先选5–8个正向案例和1–2个反例，不要求凑数或覆盖全部类别。
2. 每个作品分配稳定编号 `REF-001`，先登记到[参考索引](参考索引.csv)。只有链接、不能读取图片时，保留为“未查看”。
3. 能查看图片后，实际打开每张被引用的图，按[作品分析卡模板](作品分析卡模板.md)记录观察、设计推断、用户选择和可借鉴机制。多图作品按图片或画面编号标注，不能看一张后声称看完全部。
4. 用户明确认可后归入[认可](认可/README.md)；明确不喜欢的归入[不喜欢](不喜欢/README.md)；尚未决定的留在[待确认](待确认/README.md)。分析卡引用[图片与来源](图片与来源/README.md)中的本地素材或可访问原图。
5. 同一份 Brief 引用明确的参考编号，进入[商业提案流程](../商业提案流程/README.md)。没有读取到图片的参考不能作为已完成的逐图分析证据。

## 看图怎样拆解

围绕“具体可见证据 → 视觉机制 → 对观看和理解的作用 → 与本次商业目标的关系”分析，避免只用“高级、有冲击力”等词语。

| 维度 | 必须具体说明 |
| --- | --- |
| 摄影与光线 | 视角、透视、景别、主辅光方向、明暗和阴影关系；没有拍摄资料，不编造焦段、器材或灯位实测值 |
| 字体与文字 | 字形性格、粗细、层级、字距与图文关系；视觉推测的字体明确记为候选，不冒充真实字体识别结果 |
| 构图与阅读 | 第一视线、主体比例、空间组织、裁切、留白及观看路径；说明它们支持了哪个主信息 |
| 材质与色彩 | 可见的表面、反射、纹理、色彩关系及其情绪作用；画面表现不等于真实产品材质或工艺 |
| 商业作用 | 识别、产品利益表达、品牌记忆、差异化或行动引导；没有投放数据，只写设计意图或待验证判断 |
| 适用与边界 | 借鉴什么机制、需要如何改写、哪些产品事实和品牌资产不可直接照搬 |

## 审美选择的记录边界

- “AI推荐”“用户认可”“制作采用”“在实际投放中有效”是不同状态，分别记录。
- 用户喜欢一张作品，不代表认可其所有元素；用户不喜欢一个案例，也不自动成为永久风格禁令。
- 先保留用户原话，再提出局部推断；后续选择出现矛盾时保留上下文，不覆盖旧理由。
- 公开作品链接用于研究，不自动赋予图片再分发或商用权限。未确认能公开复制的图片可只记录出处，或使用用户有权保存的素材；不能嵌入图片时明确标记缺图。

用参考包校准的结果保存在具体项目评审中；方法经过多轮实际使用与修订后，再决定是否更新自己的 Skill。不要将这个目录视作已经验证的审美模型。
