# 跨境电商

## 用途与收录标准

Amazon商品图、A+、品牌故事、店铺与独立站等；本轮保留NED美国站任务下的两组台灯比较。

明确目标市场、实际参考页面和适用平台。当前研究的用途与原案例真实发布渠道分别记录；平台、SKU、政策或权限未知时标待核实。保留真实图像观察范围，按电商案例模板分析购买问题、信息顺序、表现方法、手机阅读、实际成果和限制。

## 文件命名

使用“品牌或作者-商品或任务简称.md”；更新同一主记录，不按日期制造重复。其他分类只链接；没有源图时不补造视觉分析。
