# 电商设计案例

## 用途

按购买任务与平台场景研究商品主图、辅图、详情、A+、品牌故事、店铺和广告；与通用摄影、渲染及视觉方法互链，不重复保存完整研究。

- [国内电商](01_国内电商/README.md)：国内商品详情等研究；未核实具体平台时明确标记。
- [跨境电商](02_跨境电商/README.md)：Amazon等跨境任务及独立站研究，记录站点／市场／版位。
- [电商案例索引](../研究模板与索引/电商案例索引.md) · [电商案例模板](../研究模板与索引/模板/电商案例分析模板.md)

## 收录标准

使用“电商案例”类型和统一YAML，写明目标市场、实际参考渠道、平台及版本；研究目标受众、商品事实、图组任务、层级、字体色彩、拍摄／渲染、手机阅读、购买入口与适用限制。官网、Amazon商品页、店铺横幅、广告不是同一版位；不能只按语言或设计师国籍归类。

按Migo实际研究任务分类时必须明确“用于跨境参考”不等于“案例本身是原生Amazon素材”。普通产品摄影仍在平面与视觉分类；通用时间表达等方法仍在设计方法专题。

## 命名

品牌或作者-商品或任务简称.md；同一案例只有一份主记录，其他分类用链接。字段未核实标待补充，不编造销量、CTR、转化、评价或A/B结果。
