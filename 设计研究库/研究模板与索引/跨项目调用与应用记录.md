# 跨项目调用与应用记录

## 调用流程

1. 明确实际任务：Migo个人IP／Beedog／个人网站／电商视觉／其他。
2. 在总索引按项目、领域、方法检索，并打开真实存在的研究文档。没有资料就明确写“本库暂无”，可以提出补研究，不能虚构已有卡片。
3. 在项目文档记录研究路径、章节、参考价值、可迁移方法、不照搬的资产或语境、适用限制。
4. 分别记录“建议／试验中／采用／未采用”，由实际决定或版本证据确认；关联项目元数据不代表采用。
5. 记录作品版本、结果与反馈。没有真实结果保持“未验证”，不能升级研究到“已应用验证”。

## 实际应用记录格式

后续每次新增一条记录，使用真实项目路径，不将下面字段当已发生事实：

| 字段 | 记录要求 |
| --- | --- |
| 日期／实际项目／任务 | 明确工作目标及可访问的项目路径 |
| 研究路径与章节 | 指向唯一主研究，不复制全文 |
| 可迁移方法／价值 | 说明解决什么问题 |
| 不照搬与限制 | 识别资产、版权、用户目标、媒介差异 |
| 采用决定及依据 | 建议、试验中、采用或未采用，引用真实反馈 |
| 版本／结果／证据链接 | 未完成就写未验证；失败也如实记录 |
| 后续修正 | 是否需要更新研究或退回待补充 |
