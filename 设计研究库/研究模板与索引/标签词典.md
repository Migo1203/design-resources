# 标签词典

标签表示文档实际讨论内容，不等于设计师的一生或用户的审美认可。每篇 3–8 个，不强制五类都选。研究涉及项目只表示参考关联，不表示已采用。

## 领域

| 标签 | 定义与边界 |
| --- | --- |
| 领域/品牌战略 | 品牌定位、受众与价值主张。 |
| 领域/视觉识别 | 标识、字体、色彩及其组合规范。 |
| 领域/字体排版 | 字形、版式、层级及阅读组织。 |
| 领域/包装设计 | 包装结构与表面信息、品牌应用。 |
| 领域/平面设计 | 平面媒介的信息与形式表达。 |
| 领域/产品设计 | 产品形态、使用关系及功能表达。 |
| 领域/UI设计 | 数字界面的可见组件与状态。 |
| 领域/UX设计 | 用户目标、任务路径与体验。 |
| 领域/角色设计 | 角色外形、人格与动作系统。 |
| 领域/插画 | 以绘画或图像语言解释与叙事。 |
| 领域/摄影 | 摄影画面的表达与使用。 |
| 领域/编辑设计 | 出版内容的组织、版式与阅读节奏。 |

## 风格

| 标签 | 定义与边界 |
| --- | --- |
| 风格/极简主义 | 通过删减建立明确关系；不是看见留白就贴标签。 |
| 风格/瑞士风格 | 有证据支持的网格、无衬线与客观信息组织传统。 |
| 风格/现代主义 | 强调结构、简化和功能的现代设计语言。 |
| 风格/后现代主义 | 对单一秩序的反思、多义与混合语言。 |
| 风格/超现实主义 | 改变日常逻辑的意象关系。 |
| 风格/编辑式设计 | 以内容、字体、图文节奏主导的视觉组织。 |
| 风格/实验性设计 | 主动测试尚未稳定的形式与媒介。 |
| 风格/几何风格 | 几何形体构成主要视觉语言。 |

## 方法

| 标签 | 定义与边界 |
| --- | --- |
| 方法/网格系统 | 用共同对齐或生成结构组织信息。 |
| 方法/模块化设计 | 以可复用单元组合和扩展。 |
| 方法/符号化 | 把对象或概念提炼成识别符号。 |
| 方法/叙事设计 | 用信息顺序或情境传达故事。 |
| 方法/信息层级 | 用比例、位置、对比区分主次。 |
| 方法/文化转译 | 将具体文化内容转成适合新语境的表达。 |
| 方法/系统化设计 | 建立跨应用的稳定规则与变化边界。 |
| 方法/跨媒介设计 | 将同一概念转为不同媒介的合适表达。 |

| 标签 | 定义与边界 |
| --- | --- |
| 行业/消费品 | 面向消费者的商品。 |

| 行业/零售 | 商店及零售服务。 |
| 行业/科技 | 技术产品、企业与研发机构。 |
| 行业/餐饮 | 食品饮料与餐饮服务。 |
| 行业/生活方式 | 日常生活观念与相关产品服务。 |
| 行业/电商 | 线上商品展示、购买与营销。 |
| 行业/教育 | 学校、课程及教育研究机构。 |

## 增补与冲突处理

先搜索本词典和现有文档，检查是否已有同义词。确需新增时在对应表中写“标签＋定义与边界”，说明真实使用文档，再重新生成索引。标签必须使用固定前缀与半角斜线。优先使用“领域/视觉识别”，不再建立“领域/VI设计”等同义标签。合并标签时同步迁移元数据并记录原因，不能悄悄丢失检索入口。
