# 研究模板与索引

本分类维护研究记录、检索和验收规则，不把管理文件计为案例。收录标准：规则必须可执行，索引来自研究文档元数据，模板说明具体证据要求。管理文件使用中文职责名，模板采用“类型＋模板.md”；README.md 保留功能名。

## 规则与记录

- [标签词典](标签词典.md)：唯一标签定义入口。
- [研究状态说明](研究状态说明.md)：状态依据、转移与完成条件。
- [来源与核验规范](来源与核验规范.md)：A/B/C、事实/推断/建议、图像和版权边界。
- [跨项目调用与应用记录](跨项目调用与应用记录.md)：真实调用、采用和结果记录。
- [资料来源清单](资料来源清单.md)：首批研究的原始链接与访问情况。
- [建设与验收记录](建设与验收记录.md)：原仓库审计、保护范围、检查结果与未完成项。

## 索引生成与检查

从仓库根目录运行，Python 3.10+，依赖 PyYAML（缺失时安装 `python -m pip install PyYAML`）：

```bash
python 设计研究库/研究模板与索引/脚本/维护研究索引.py --write
python 设计研究库/研究模板与索引/脚本/维护研究索引.py --check
```

脚本按分类配置扫描01–06及不编号的设计方法、教程目录下的实际研究Markdown，排除 README；人物目录内的理念／代表作按真实类型跨索引收录；检查 YAML、必填项、日期、标签、目录与类型、核心结论条数、必要章节、来源和索引一致性。同步检查本库及根目录入口的本地 Markdown 文件链接与锚点。模板也校验 YAML，但不进入索引。脚本检查无法替代事实核验、真实看图或用户验收，不自动升级状态，也不把 URL 可打开当作事实正确。

GitHub 可直接阅读 Markdown。用页面查找检索姓名／标签；在本地可用：

```bash
rg -n '方法/网格系统|项目/个人网站' 设计研究库
rg -n '^研究状态: 待补充' 设计研究库
```
