# 角色品牌｜六案例横向比较

## 研究目的

集中维护跨六案的比较方法，链接六份主档，项目策略仍由品牌仓库维护。

这是对已有项目研究的归纳归档。原始讲解、完整截图与反馈历史保留在来源仓库，本库维护一份可检索主记录。以下事实／观察均注明继承范围；分析和建议不视为用户认可。

## 核心结论

1. 六案比较的颗粒度是角色任务、识别线索、变化和触点，而不是谁更成功。
2. 稳定关系与情境变化可以同时成立；反白适配有时需要改具体画法，而不是机械反色。
3. 非语言角色动作和个人专业贡献是不同证据；认真不能只由金属感或整齐排版宣称。
4. 资料深度、团队规模和选样都不一致，不能把六案当控制变量实验或证明个人品牌必须有角色。
