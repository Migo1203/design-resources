# 设计师档案

## 分类用途

研究设计师的判断方式、作品证据和合作角色，不以名气替代分析。

## 收录标准

必须覆盖六个维度、至少三个作品且一个深入拆解；逐项核对个人与团队分工。

所有实际研究均需 YAML 元信息、3–8 个已定义标签、研究目的、3–5 条核心结论、真实案例证据、设计分析、学习价值、来源与关联项目。资料不足时保持“待研究 / 研究中 / 待补充”，不凑文章。

## 文件命名与维护

人物中文名/设计师档案.md、设计理念.md、代表作品/案例名.md；无稳定译名时保留英文姓名，避免同一人重复建档。理念与案例沿用对应模板和真实YAML类型，分类索引跨目录收录，不复制全文。旧平铺路径只作兼容导航。

更新同一研究时保留历史和修正依据，不按日期复制出重复研究。图片只保留有权限的文件；默认引用原始作品页。模板必须复制后填入实际信息，README 本身不计为研究文档。
