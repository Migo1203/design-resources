# Yukai Du：情绪、几何叙事与静动转换

## 研究目的

把几何风格、情绪叙事与动画分开理解，为Beedog未来动态表达形成问题清单。

## 核心结论

1. **本人观点**：校友访谈强调提问以理解Brief和解决创作阻碍，风格并非先于问题（Y2）。
2. **事实**：Nike动作角色、NYT编辑插画、MTV情绪片承担不同内容任务与协作方式（Y3—Y6）。
3. **视觉分析**：MTV采样中环境尺度与眼睛／屏幕增多参与情绪，角色脸部不是唯一叙事渠道。
4. **建议**：先定义情境、关键姿态和视觉层级，再扩展动效；参考风格不成为Migo最终规范。

## 方法定义、问题与执行步骤

明确内容问题 → 写情绪变化／行动句 → 画静态关键姿态与环境关系 → 选有限形体和纹理规则 → 规划哪里动、哪里稳定 → 与动画执行者明确层级和交付 → 检查静帧能否仍理解。此流程为本库归纳，不冒充完整作者制作流程。

## 实际案例与局限

[MTV](代表作品/MTV焦虑短片.md)以环境压力表达未知来电；[Nike](代表作品/Nike巴特西角色与动画.md)以不同姿势组成商业角色；[NYT](代表作品/纽约时报工作指南插画.md)用头图与辅图区分内容层级。角色动作适合情绪／叙事；导航反馈、加载状态等网站交互还需要UX和性能依据，不能用好看的影片替代。

## 学习价值与迁移边界

Beedog保留圆鼓脸颊、犬类结构、尖耳与微妙眼神，用身体和道具补充探索感。Migo网站动效先保证作品可读，不复制紫色焦虑情境或全屏广告片。未验证动作可读性前，不标已应用验证。没有新增标签，采用既有插画、叙事、跨媒介标签。
