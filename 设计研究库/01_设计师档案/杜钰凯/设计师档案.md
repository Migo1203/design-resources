# 杜钰凯（Yukai Du）

## 研究目的

理解几何人物、色彩和动态怎样服务情绪与商业内容。分别研究Nike商业角色、NYT编辑插画、MTV情绪动画；重点把可见动作和分工记录清楚，不把个人风格当Beedog最终方案。

## 核心结论

1. **事实**：官网与中央圣马丁本人访谈交叉核实广州背景、动画学习和职业；中文名杜钰凯由本人官网确认（Y1、Y2）。
2. **事实**：Nike作品有插画／动画导演、动画执行和清稿分工；静态角色与4段门面循环是不同交付，不是她独自逐帧完成（Y3、Y4）。
3. **视觉分析**：MTV已看片段中人物由静坐转为防御姿态，环境眼睛／屏幕增多并改变尺度，情绪不只靠面部表情（Y6）。
4. **事实＋分析**：NYT为动态头图加6张辅图；所看有限样本以空间框架串联工作情境，图像系统服务内容结构（Y5）。
5. **建议**：Beedog先定义情绪触发与动作逻辑，再考虑循环；Migo网站的装饰动效应服从内容阅读，未采用、未测试。

## 04 设计特点

| 维度 | 可见证据与范围 |
| --- | --- |
| 字体排版 | 所看Nike人物图和NYT插画不是字体系统；MTV出现客户字标，不称其设计该Logo；字库未知 |
| 色彩 | Nike蓝与黄／浅色，NYT多色块，MTV紫色集中；同一作者可以不同情绪配色，无通用色号 |
| 构图 | Nike斜向肢体、NYT框中框与工作场景、MTV中心人物与环境扩张，各自服务内容 |
| 材质表现 | 点线纹理造成手绘感，不等于实物印刷工艺；官网称手绘敏感性，不证明所有元素纸上完成 |
| 角色与识别 | 简化脸部可由姿态和环境讲情绪；不等于Beedog应该去掉微妙眼神 |
| 静动关系 | GIF采样可见环境和人物关系变化；没有全片和音轨，不猜BPM、缓动曲线或制作软件版本 |
| 跨项目一致性 | 几何、纹理与叙事意识稳定，具体色彩、尺度和动作按任务改变 |

## 学习价值与迁移边界

| 方法 | Migo／Beedog建议 | 不照搬／局限 | 未来检验 |
| --- | --- | --- | --- |
| 用姿态讲情绪 | Beedog先写好奇→尝试→笨拙→发现情境 | 不复制几何人形或去掉犬类记忆点 | 静帧能否读出动作意图 |
| 动态先有叙事目的 | “你好，我是Migo”动效先明确出现／结束与内容关系 | 本轮不改网站，不把MTV压迫情绪搬进欢迎页 | 测跳过、减少动态、加载后可读性 |
| 同源视觉跨媒介 | 日后角色静图、WebP／SVG和循环分别交付 | 不假设SVG自动可动或全GIF适合上线 | 检查性能、尺寸、降级静帧 |
| 角色家族先有规则 | 固定Beedog比例，再讨论动作差异 | Nike一组人物不等于可自由复制的角色库 | 日后标准图、表情和动作互相对照 |
