# 亚伦·德拉普林（Aaron Draplin）

## 研究目的

研究从小型真实需求开始的商业图形：如何先画、比较和简化，怎样跨印刷、服饰、标识保持识别。以Field Notes深入拆解，对照Coal与Cobra，避免把“粗线、橙色、复古”当完整方法。

## 核心结论

1. **事实**：Field Notes由DDC与Coudal Partners共同建立；学校和双方记录均确认Draplin与Jim Coudal关系，非一人包办（D2—D4）。
2. **事实**：Field Notes规格记录尺寸、纸张、印色、Futura与制作来源，说明品牌可从小载体与重复生产形成系统（D5）。
3. **事实**：Coal有Brad Scheuffele、摄影团队等协作，2003字标与2018追加图形分开；不能把所有头饰、照片归Draplin（D6）。
4. **分析**：Cobra从草图到轮廓化商标能看到哪些信息被保留；夸张图形适合业务情绪，但不是所有角色都需厚重攻击性（D7、D8）。
5. **本人方法**：访谈先讨论问题、看市场、做草图和细化，反对只靠效果图；本库不把这一流程当唯一标准（D8）。

## 04 设计特点

| 维度 | 证据与边界 |
| --- | --- |
| 字体 | Field Notes有Futura规格；Cobra粗圆名称与图形成组；Coal字标较轻，不能泛称全部粗字 |
| 色彩 | Field Notes牛皮色／黑、Coal蓝灰／白、Cobra黄红；不以个人橙色形象代替每件作品 |
| 构图 | 少量主形和明确排版层级，需按载体判断；Cobra集中、Coal字标横向、笔记本留写作空间 |
| 材质 | Field Notes规格有来源，其他照片不推断纸张／刺绣密度；未触摸实物 |
| 品牌识别 | 固定骨架适配多应用，但留白和繁简随业务改变 |
| 内容关系 | 实用记录、头饰人物、餐饮趣味各有不同情绪和信息要求 |
| 跨项目一致性 | 工具和观察方法有连续性，不强求全部复古徽章化 |

## 学习价值与迁移边界

| 方法 | 建议用途 | 不照搬／局限 | 日后检验 |

| 生产与署名也属设计 | 导出清单记录格式、用途、版本、人员 | 不把商标图当全套IP或素材许可 | 检查后续资产能否被网站正确调用 |
