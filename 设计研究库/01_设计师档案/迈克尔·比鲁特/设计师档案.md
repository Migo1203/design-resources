# 迈克尔·比鲁特（Michael Bierut）

## 研究目的

研究商业约束怎样变成清晰的识别系统，重点比较历史资产、组织关系和参与式传播三种不同起点。MIT深入拆解；按本轮要求补Mastercard、Hillary，并保留Saks及Yale后续线索。

## 核心结论

1. **事实**：Mastercard由Bierut、Luke Hayman及团队协作；参与者记录区分Hamish Smyth的标志执行与Trabucco-Campos的系统设计，不能全归Bierut（B3、B4）。
2. **事实**：MIT新系统以已有七乘七网格发展ML和23组图形；Bierut与Aron Fay参与，前案Richard The及其合作历史另记（B5、B6）。
3. **事实**：Hillary核心系统与Jesse Reed协作，字体有Lucas Sharp参与；Jennifer Kinon及竞选团队扩展，不是Bierut独立包办整届竞选（B7、B8）。
4. **分析**：方法相通之处是保留一个可解释的核心，再规定变化，而不是所有客户统一用网格或同一字体。
5. **边界**：品牌陈述和本人复盘能说明意图，不能证明销售、机构效率或选举结果由设计造成。

## 04 设计特点

| 维度 | 案例证据与边界 |
| --- | --- |
| 字体排版 | MIT用Helvetica和层级，Mastercard用FF Mark，Hillary字体有专门协作；不是凭图猜同款无衬线 |
| 色彩 | MIT/Saks所看黑白，Mastercard红黄橙，H变体蓝白红；不能概括其“只做黑白极简” |
| 构图 | MIT网格组织多单位，Saks切分历史书写，Mastercard稳定双圆，H保持形态允许内容变化 |
| 材质表现 | 所看为屏幕标志、场所与包装照片；未实测油墨、卡面工艺或空间导向效率 |
| 识别 | 稳定核心与变化层分开，具体由组织需求决定；新品牌不能先打散尚未形成的记忆 |
| 内容关系 | 机构复杂性、支付渠道、公众参与、零售历史各有不同任务 |
| 跨项目一致性 | 共同的是研究商业条件与系统落地，不是同一视觉模板 |
