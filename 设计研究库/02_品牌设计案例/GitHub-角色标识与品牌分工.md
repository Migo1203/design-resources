# GitHub｜角色、标识与品牌分工

## 研究目的

区分图形标识、字标、完整角色和辅助图形，保留从早期研究入口到正式讲解的进度。

这是对已有项目研究的归纳归档。原始讲解、完整截图与反馈历史保留在来源仓库，本库维护一份可检索主记录。以下事实／观察均注明继承范围；分析和建议不视为用户认可。

## 核心结论

1. 后续研究已读Logo、Mascots、Typography、Color、Illustration并记录十张截图，早期文字入口不是最新研究范围。
2. 原官方资料把Invertocat的识别用途与Mona等角色表达分开；资产间有联系，不代表用途完全相同。
3. 能否省略品牌名称取决于观者已知信息；大型平台的认知积累不能转借给新个人品牌。
4. 角色、主题变体与插画需要场景条件，不能因为有下载素材就视为可任意改编。

## 案例证据与历史查看范围

原研究2026-11-11查看六个官方栏目和十张截图，包括标识留白／组合、Mona多视角、配色、正误例、字体层级、色板、插画与首页；未核对所有产品或传播成效。本轮只归档原记录。
