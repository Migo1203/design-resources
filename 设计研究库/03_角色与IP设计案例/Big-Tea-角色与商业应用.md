# Big Tea｜角色与商业视觉应用

## 研究目的

归档已确认作者官网和六图观察，替换早期仅有Behance受限候选的片面进度。

这是对已有项目研究的归纳归档。原始讲解、完整截图与反馈历史保留在来源仓库，本库维护一份可检索主记录。以下事实／观察均注明继承范围；分析和建议不视为用户认可。

## 核心结论

1. 后续已通过作者官网与公开嵌入页核对Studio Moara署名，并实际研究六幅，不能只保留早期“案例未核实”。
2. 作者将项目表述为茶品牌与吉祥物设计；品牌故事与功效文案未独立核验，不当健康或经营事实。
3. 原六图涵盖字标、文字互动、动作、名片、包装袋和帆布袋，可比较跨触点信息主次。
4. 动作与茶杯情境共同承担人格表达；样机和作者展示不能证明量产、销售或传播成效。

## 设计分析

下表是对原记录的归纳；未取得的资料保持待补充，不用常识补造作者意图或完整系统。

| 维度 | 证据、分析与边界 |
| --- | --- |
| 角色定位与人格 | 作者希望茶品牌大胆有活力、带街头文化与幽默；这是自述方向，受众年龄和价格带未知。 |
| 视觉识别 | 原研究记录厚重字标、饱满体形、描线与茶杯的持续关系。 |
| 表情动作 | 坐卧、泡茶、举杯和文字互动把人格落到情境，而非靠台词解释全部。 |
| 色彩与字体 | 作者图中有鲜明配色与字形对比；字体文件、色值和授权未取得。 |
| 应用与商业延展 | 名片、包装与帆布袋有不同主次；均只作为应用展示，商业委托与量产仍待核实。 |

## 学习价值与不照搬部分

将人格词翻译为动作与对象关系，再检查不同触点的主次。不复制Big Tea的形象、字标、饱满体量和包装；Beedog的机械化或色彩选择留在品牌项目。
