# Slligy｜个人品牌与原创角色系统

## 研究目的

整合资料导读与后续八图研究，分析角色如何进入个人创作身份与作品展示。

这是对已有项目研究的归纳归档。原始讲解、完整截图与反馈历史保留在来源仓库，本库维护一份可检索主记录。以下事实／观察均注明继承范围；分析和建议不视为用户认可。

## 核心结论

1. Dprofile作者署名Vyacheslav Lipin；原研究已核对其主页，不再停留在早期“只读取标题”的状态。
2. 原项目把品牌与角色描述为同名；Migo与Beedog的既定关系不同，不能直接套用命名架构。
3. 源图2、5、6、9、10、11、14、16支持对字标、角色、草图、模型和应用的比较；不是完整生产过程证明。
4. 角色的稳定眼部／宽嘴线索、动作和跨形式变化可供研究；模型骨架与样机不能证明动画验证、量产或销售。

## 学习价值与不照搬部分

先比较稳定形态再做动作；让字标、标题、角色和图案各有职责。Beedog不挪用眼球、尖牙、同名方式或整套高饱和形式，制作规模按当前需求收敛。
