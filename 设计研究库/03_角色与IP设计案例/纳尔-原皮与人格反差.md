# 纳尔｜原皮视觉与人格反差

## 研究目的

归档已进行的官方原皮与AC3概念比较，分开本人偏好、角色设定与原创性判断。

这是对已有项目研究的归纳归档。原始讲解、完整截图与反馈历史保留在来源仓库，本库维护一份可检索主记录。以下事实／观察均注明继承范围；分析和建议不视为用户认可。

## 核心结论

1. 原研究实际看过官方1215×717原皮插画和AC3三角度概念；技能演示仅取得文件，尚未播放。
2. 俯身的小纳尔插画不足以测直立头身比或说明正侧背结构。
3. 好奇／顽皮与力量反差可讨论，但Migo无需继承愤怒、失控、巨兽变身或武器。
4. 本人喜欢AC3和大耳、毛发、双足等已在项目记录；这不证明原创性核查完成，也不自动确定新名称。

## 案例证据与历史查看范围

原研究2026-11-12官方原皮完整插画、AC3 V02三角度；未看其他皮肤、未完成视频或完整同类检索。本轮只归档，不重新生成或修改角色。

下表是对原记录的归纳；未取得的资料保持待补充，不用常识补造作者意图或完整系统。

| 维度 | 证据、分析与边界 |
| --- | --- |
| 角色定位与人格 | 官方文字描述远古约德尔人及怒气变身；本人要学的是探索气质与形态反差。 |
| 视觉与识别 | 原记录比较大耳、毛发、脸部分色和器物；两图姿态不同，不能精确比较全身比例。 |
| 表情动作 | 小纳尔俯身靠近目标，AC3站姿更规整；可研究动作与观察对象的关系。 |
| 应用与延展 | 证据是游戏官方插画和个人概念对照，没有Beedog实际商业应用。 |
| 独立性边界 | 颜色不同不等于原创；犬类结构、双叶耳翼与更多相近角色仍需带来源比较。 |
