# Migo 设计研究库

这里是 Migo 长期使用的设计研究与知识资产库，服务于个人品牌、Beedog、个人网站、电商视觉和未来项目。

工作流程：发现对象 → 收集可靠来源 → 查看作品 → 拆解方法 → 形成判断 → 在项目中尝试 → 记录结果与修正。

## 如何使用

1. 从[研究总索引](08_研究模板与索引/研究总索引.md)按姓名、标签、关联项目或状态找到真实文档。
2. 新建研究前查重；按[对应模板](08_研究模板与索引/README.md)建立 Markdown，填写 YAML、研究目的和待补项。默认状态为“待研究”，开始查资料后如实调整。
3. 用[标签词典](08_研究模板与索引/标签词典.md)中的 3–8 个标签；具体结论回链到来源编号。正文分别注明“可核实事实 / 分析推断 / 个人设计建议”。
4. 实际打开引用图像，记录原始页面、图号、日期与查看范围。这里只保存分析和原始链接，默认不提交外部图片、字体或样机。
5. 通过[来源与核验规范](08_研究模板与索引/来源与核验规范.md)和[状态标准](08_研究模板与索引/研究状态说明.md)检查；随后重新生成索引并运行校验。
6. 跨项目使用时按[调用与应用记录](08_研究模板与索引/跨项目调用与应用记录.md)记录目标、方法、边界和实际结果。未采用也可记原因。

## 当前进度与边界

首批是原研哉、保罗·兰德（Paul Rand）、迈克尔·比鲁特（Michael Bierut）三份档案。每份均有六维研究、至少两个作品和一个深入拆解；尚有署名、原始著述或应用证据待补，状态均为“待补充”。具体进度以自动生成索引和档案为准。

首轮作品分析保存在人物档案内，其他案例分类暂不重复建同文档；需要独立扩展时在案例分类建主卡，并将人物档案改为摘要链接。分类 README 和空索引说明是维护规则，不冒充研究成果。

[审美参考包](../审美参考包/README.md)记录用户明确的喜好或未决定状态；本库记录研究证据与方法。可以互相链接，但不复制同份完整研究，也不自动产生用户认可。
