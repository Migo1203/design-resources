# Migo 设计研究库

这里是 Migo 长期使用的设计研究与知识资产库，服务于个人品牌、Beedog、个人网站、电商视觉和未来项目。

工作流程：发现对象 → 收集可靠来源 → 查看作品 → 拆解方法 → 形成判断 → 在项目中尝试 → 记录结果与修正。

## 如何使用

1. 从[研究总索引](研究模板与索引/研究总索引.md)按姓名、标签、关联项目或状态找到真实文档。
2. 新建研究前查重；按[对应模板](研究模板与索引/README.md)建立 Markdown，填写 YAML、研究目的和待补项。默认状态为“待研究”，开始查资料后如实调整。
3. 用[标签词典](研究模板与索引/标签词典.md)中的 3–8 个标签；具体结论回链到来源编号。正文分别注明“可核实事实 / 分析推断 / 个人设计建议”。
4. 实际打开引用图像，记录原始页面、图号、日期与查看范围。这里只保存分析和原始链接，默认不提交外部图片、字体或样机。
5. 通过[来源与核验规范](研究模板与索引/来源与核验规范.md)和[状态标准](研究模板与索引/研究状态说明.md)检查；随后重新生成索引并运行校验。
6. 跨项目使用时按[调用与应用记录](研究模板与索引/跨项目调用与应用记录.md)记录目标、方法、边界和实际结果。未采用也可记原因。
