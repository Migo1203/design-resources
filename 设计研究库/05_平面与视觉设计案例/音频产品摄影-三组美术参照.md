# 音频产品摄影｜三组美术参照

## 研究目的

保存Lexon、STUDIO/BOWEN与Kusk的美术观察；同文中的Sony归入三品牌产品视觉主档，避免重复完整记录。

这是对已有项目研究的归纳归档。原始讲解、完整截图与反馈历史保留在来源仓库，本库维护一份可检索主记录。以下事实／观察均注明继承范围；分析和建议不视为用户认可。

## 核心结论

1. Lexon官方图有手持、桌面与其他功能图；产品设计署名不等于摄影署名。
2. STUDIO/BOWEN自述参与Google Brand Studios摄影美术与社交内容，原研究只选音箱画面，不归为其全部独立设计。
3. Kusk的B&O SS19记录摄影／艺术指导Lasse Kusk等团队，项目名不等于核实完整发布日期。
4. 小度三张概念效果通过不代表本人逐一认可所有参考，方向采用与单案喜好须分开。

## 案例证据与历史查看范围

原研究2026-10-28按图记录手持／桌面、音箱生活摄影、B&O近景；未完成全商品页或消费者研究。本轮读取笔记。

## 设计分析

下表是对原记录的归纳；未取得的资料保持待补充，不用常识补造作者意图或完整系统。

| 维度 | 证据、分析与边界 |
| --- | --- |
| 构图摄影 | 手与小物接触、设备进入生活空间、曲面与孔纹近景提供不同证据。 |
| 字体色彩 | 参考职责主要为光影、尺度与材质，不从图片猜完整字库或官方VI。 |
| 视觉传达 | 生活数码亲近感来自具体动作和可辨产品，而不是复制另一品牌背景。 |
| 署名边界 | 产品设计、摄影、美术指导与代理分别记录；不把完整团队成果全部归某一设计师。 |
