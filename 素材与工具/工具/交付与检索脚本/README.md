# 图片交付与素材检索

这两份工具由本库编写，沿用根目录[MIT许可证](../../../LICENSE)，不是下载的第三方软件或品牌资产。脚本与素材数量分开登记，不改变任何素材的候选／采用状态。2026-11-14检查环境：Python 3、Pillow 12.3.0（WebP可用）。没有新增软件安装包。

## 素材检索

[素材检索.py](素材检索.py)只用Python标准库，默认读取本仓库统一素材清单。可从任意工作目录调用，输入路径用脚本的实际路径即可。

在仓库根目录运行：

```bash
python 素材与工具/工具/交付与检索脚本/素材检索.py --分类 音乐与音效
python 素材与工具/工具/交付与检索脚本/素材检索.py --格式 svg --关键词 "lucide arrow" --上限 10
python 素材与工具/工具/交付与检索脚本/素材检索.py --编号 字003 --json
python 素材与工具/工具/交付与检索脚本/素材检索.py --统计
```

分类为精确匹配，格式不区分大小写，关键词按空格拆分并同时匹配清单记录的全部字段。默认显示前20项；`--json`提供结构化结果，`--统计`返回匹配项分类与原件字节数。检索不到时返回空集，不编造素材。工具不下载、复制或修改原件，也不会自动搜索远程网站。

## 图片交付

[图片交付.py](图片交付.py)依赖Pillow；读取明确指定的静态图片，导出到**尚不存在的新目录**，附一份`交付清单.json`。本轮仅在临时生成的合成测试图片上运行，没有改动用户照片、素材原件或其他项目。

示例中输入文件与输出目录由你替换；输出目录必须是新的：

```bash
python 素材与工具/工具/交付与检索脚本/图片交付.py "工作图/项目封面.png" --输出 "交付/项目封面_webp" --格式 webp --长边 1600 --质量 85
```

| 参数／行为 | 说明 |
| --- | --- |
| 输入 | 一张或多张明确指定的本地图片；不递归扫描目录、不联网 |
| `--输出` | 必填；已存在的目录会被拒绝，避免覆盖原件或旧交付 |
| `--格式` | webp／png／jpeg，默认webp |
| `--长边` | 默认1600像素；按比例缩小，绝不放大 |
| `--质量` | 默认85，范围1–100，仅作用于WebP／JPEG；有损质量不是视觉保真度评分 |
| 透明 | WebP／PNG保留透明；JPEG合成白底 |
| 方向与元数据 | 按EXIF方向纠正后导出，移除EXIF定位等信息；这不是全部隐私或内容审查 |
| 色彩 | RGB ICC转换到sRGB；无ICC按sRGB假定并写入记录，不能称为色彩校准 |
| 拒绝条件 | 同名目标、旧输出、动画／多页、CMYK等需单独管理的颜色模式；RGB以外ICC配置不自动转换 |
| 报告 | 每批一份JSON，记录源路径、SHA256、方向、色彩假设、尺寸、输出字节数与哈希 |

输入文件名相同但扩展名不同，导出同一格式后也可能重名，工具会在写入前拒绝。输入与输出SHA256用于追溯，不能据此证明获得图片许可。输入图片需自行拥有处理权；导出不等于正式采用或无障碍、SEO与网站性能验收。大量超大图片建议分批运行，工具预检会在内存中持有本批图像。

如果本机没有Pillow，请在自己的Python虚拟环境中安装；本次环境已有Pillow，没有为运行工具追加系统软件。浏览器截图与音频读取依赖分别由相关预览脚本声明，这两份工具不要求FFmpeg或Playwright。

- 图片：透明WebP尺寸与Alpha、JPEG白底、RGB ICC转换路径、EXIF旋转且不放大、已有输出保护、同名拒绝、CMYK拒绝、输入哈希未变。
- 检索：音乐7项、字003精确查询、2,055个Lucide SVG、无结果返回空集；查询前后清单哈希未变。
- [技术检查记录](../管理资料/工具检查记录.json)集中保存，不在每个脚本旁增加元数据文件。重跑[检查脚本](../../脚本/检查交付与检索工具.py)需要Pillow，只生成临时合成图片并更新该记录。

这些是已覆盖的边界与样本，不代表所有色彩配置、全部图像格式、真实设备或专业印刷流程均已验证。需要AVIF、视频转码、PSD智能对象时另开明确任务，不默认扩张工具范围。
