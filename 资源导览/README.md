# 设计资源整合｜资源导览

整理日期：2026-10-27。依据[中文资源目录](../readme.md)及[原始英文目录](../README.en.md)整理，面向 Migo 的音箱商业视觉、PS 制作与求职作品集需求。目录统计以整理时的版本为准。

网站资源按需查阅；具体作品及用户取舍放入[审美参考包](../审美参考包/README.md)，实际项目按[商业提案流程](../商业提案流程/README.md)推进，用[可视化提案模板](../提案模板/README.md)比较方向。

这是一份面向设计师和前端开发者的网站链接目录，包含 **33 类、1,249 条表格资源条目**。数量按条目计算，同一网站可能重复出现，不代表1,249个独立网站，也不是已下载好的素材包。

本导览未逐站核验资源的实时可用性、收费与许可证。原目录的“免费”描述不能替代具体素材的许可。

## 内容结构与适用性分析

这份目录同时面向设计师与前端开发者，分类明显偏网页/UI。12类前端模板、CSS、JavaScript和组件库共414条，约占全部条目的33.1%；“设计灵感”的48条里也有大量网站、App和网页组件案例。不能把所有“设计”条目都理解为适合产品广告。

它的优势是覆盖广、便于带着具体问题找入口；不足是条目通常只有一句介绍，缺少适用任务、中文支持、学习成本、导出格式和许可核验时间。104条在线设计工具与51条图像压缩/转换条目存在大量功能替代，实际无需逐个试用。

当前最重要的能力缺口是“产品事实与购买理由→画面点子→产品视角、光影、材质与构图→关键画面验证”。这个目录提供参考和工具入口，不能自行完成这条推导，也不提供你的PSD审稿或产品外观核对。

三个仓库可形成工作链：`design-resources`查找参考和工具，`AI-Skills`保存可复用方法，`AIGC`记录真实项目、制作迭代与采用结果。资源数量不作为项目进度指标。

目录自身保留Brad Traversy的MIT版权说明。MIT许可适用于目录自身，不自动授权外链网站的字体、图片、音乐或样机。仓库的贡献校验脚本检查提交格式与改动范围，不会实际验证外链状态、收费或素材授权。顶部暂停新增的说明来自现有目录维护规则；你后续建设自己的资源库时，可以保留原始来源与目录，另建中文精选入口。

## 当前最值得用的资源

以2026-10-27的音箱项目阶段为例：先重整商业视觉方向，比较“精致生活数码”和“科技产品力”，完成两张不同职责的关键画面；网站和视频属于后续阶段。后续按实际项目阶段调整优先级。

| 用途 | 目录内资源 | 对你怎么用 |
| --- | --- | --- |
| 商业美术与案例参考 | [Behance](https://www.behance.net/) | 搜索 `speaker campaign`、`audio product advertising`、`consumer electronics key visual`。优先看完整商业案例，观察卖点、产品视角、光线、材质与系列变化，不只抄字号和位置。 |
| 系列配色 | [Adobe Color](https://color.adobe.com/create)、[Color Hunt](https://colorhunt.co/) | 从现有暖生活图片整理主色、背景色、强调色，再与科技方向比较。配色服务于产品和画面，不随机换流行色卡。 |
| 生活方式场景与摄影参考 | [Kaboom Pics](https://kaboompics.com/)、[Pexels](https://www.pexels.com/)、[Unsplash](https://unsplash.com/) | 查窗边、书桌、木材、布料、野餐的光线与道具关系；需要合成时另核对具体素材许可、清晰度和透视。其他音箱照片不作为小度产品替身。 |
| 中文排版字体 | [Google Fonts](https://fonts.google.com/) | 筛选支持简体中文的字体，可检索 Noto Sans SC、Noto Serif SC；这两个字体名是使用建议，不是原目录单列条目。具体字重、字库与许可按下载项确认。 |
| 求职案例应用展示 | [Mockup World](https://www.mockupworld.co/) | 最终海报完成后挑少量展板、画框、灯箱或画册PSD样机。保留清楚的原图展示，应用样机标明概念展示，不冒充真实客户投放。 |
| 预览图压缩 | [Squoosh](https://squoosh.app/)、[TinyPNG](https://tinypng.com/) | 为GitHub、投递或未来网站制作轻量预览图；保留PSD和高质量母版，检查小字、网孔和渐变。 |
| PSD备用工具 | [Photopea](https://www.photopea.com) | 无法使用PS时临时查看或编辑PSD。你已有PS，无需更换主工具；复杂智能对象、字体和效果需实际复核。 |
| 电商信息组织 | [ecomm.design](https://ecomm.design/) | 参考品牌电商网站如何组织产品首屏、卖点与详情叙事。它偏品牌网站，不是国内电商平台尺寸或主图规范库。 |

建议先用前三类完成这一小步：在Behance为两个方向各选3张参考，分别记录“核心卖点、产品视角、光线和材质、自己可借鉴的表达”；再用Adobe Color整理成两组配色。先形成方向比较和两张职责不同的构图草案，再验证并展开整套设计。

## 哪些描述需要核实

- Graphic Burger 条目明确写有免费与付费内容混合，且可能含赞助内容。
- Smart Mockups、Media Modifier、Canva、Figma等条目原文已提及付费选项；PolyGlyph的注册赠送额度不等于无限免费。
- 字体聚合站需逐字体检查中文覆盖及商业许可；图库、样机也需逐素材确认授权。
- Adobe XD、InVision相关条目及一些旧服务链接需要优先核验，不应仅凭旧目录说明建立长期工作流。
- 原README说明自2026-10-18起暂停新增资源，目录继续保留供参考。这不代表所有链接或收费描述都经过本次核验。
