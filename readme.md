# 设计资源整合

为商业电商、品牌、IP与艺术创作建立可查阅的资源入口、审美参考与提案工作流程。先比较创意，再看可视化方案，用真实选择校准方法，之后进入提示词和PS执行。

| 从哪里开始 | 内容 |
| --- | --- |
| [审美参考包](审美参考包/README.md) | 收录你认可与不喜欢的具体作品，实际看图拆解摄影、字体、构图、材质及其作用 |
| [商业提案流程](商业提案流程/README.md) | 固定同一份Brief，比较三个有实质差异的创意方向，记录选择与修订 |
| [可视化提案模板](提案模板/README.md) | 用参考图、色板、字体样张和构图线框组成离线HTML提案，可打印为PDF |
| [中文资源导览](资源导览/README.md) | 33类、1,249条资源的概览与当前适用建议 |
| [原始英文目录](README.en.md) | 保留上游英文原文，方便核对翻译与来源 |

**当前进度：参考包与流程已建立，尚待收录用户选定作品；HTML为待填模板，真实提案和用户评审尚未开始。** 网站推荐不自动代表你的审美认可，本轮不直接生图、不修改自己的Skill。

以下为资源目录的中文翻译，保留品牌名、原始链接、免费限制及原文中的数字。条目描述来自原目录，未逐站核验最新可用性或许可。MIT适用于目录本身，不自动授予外链素材商用权限。

> 下方“暂停新增”说明保留了原资源目录的外部投稿规则，不限制本仓库经用户授权建立审美参考与提案资料。

>
> 本仓库继续作为精选资源目录供查阅，但目前不接收新增资源。请仅通过 Issue 报告链接失效、资源不再免费或既有描述不准确等问题。2026年10月18日之前已打开的 Pull Request 仍按原贡献规则审核。
